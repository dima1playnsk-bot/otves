# «Отвес» — демо-сайт строительной компании

Анимированный одностраничный сайт вымышленной компании, которая строит частные дома в Новосибирске.

Сайт: https://dima1playnsk-bot.github.io/otves/

## Что внутри

- Заставка при первом заходе: отвес падает и выставляет уровень.
- Первый экран: фото зимнего дома проявляется из чертёжной сетки, идёт снег, подписи «−40° на улице / +22° в доме».
- Стройка по прокрутке: 6 фото этапов (чертёж, фундамент, стены, кровля, фасад, готовый дом) сменяют друг друга, рядом — список этапов и счётчик недель. Есть кнопка «Пропустить этапы».
- Проекты листаются вбок; фото сначала синее, как чертёж, и проявляется в цвет.
- Калькулятор стоимости: фото дома из выбранного материала, подсказки про материалы, цена «набегает».
- Секция с цифрами, гарантии, частые вопросы, форма заявки на крюке крана (демо: заявка никуда не отправляется).
- На телефоне — нижняя панель «Позвонить / Получить смету», в калькуляторе она показывает текущую цену.
- Отвес справа (на больших экранах) опускается по мере прокрутки и качается от скорости.
- Своя страница 404.

## Технологии

HTML, CSS и JavaScript без сборки. Анимации — GSAP и ScrollTrigger, плавная прокрутка — Lenis (подключены с CDN).
Фото — с [Unsplash](https://unsplash.com), подгружаются по ссылкам с их сервера.

Если в системе выключены анимации, сайт показывается спокойным, а посетитель может включить их кнопкой «Включить анимацию» или открыть адрес с `?motion=1`.

## Запуск у себя

```bash
python -m http.server 5190
```

Затем открыть http://127.0.0.1:5190.

Компания, адрес, телефон и цены вымышленные.
