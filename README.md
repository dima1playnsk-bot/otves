# Отвес — бизнесы Новосибирска без сайта

Сайт: https://dima1playnsk-bot.github.io/otves/

Кнопка «Искать» показывает на карте все бизнесы Новосибирска (20 видов: парикмахерские, кафе, автосервисы и т. д.), у которых нет своего сайта. Сюда же попадают те, у кого вместо сайта только ВКонтакте, Telegram, DIKIDI, YCLIENTS и т. п.

- Клик по точке — карточка бизнеса: телефоны, почта, соцсети, часы, ссылки на Яндекс Карты и 2ГИС.
- Виды бизнеса, телефон, сети, статус и название — фильтры.
- Статусы и заметки хранятся в браузере, вкладка «Лиды» выгружает их в CSV для Excel.

## Данные

`data/novosibirsk.json` раз в день обновляет GitHub Actions (`.github/workflows/data.yml` → `scripts/fetch-data.mjs`) из OpenStreetMap через Overpass API. Поэтому поиск на сайте мгновенный. Если файла нет, сайт спрашивает Overpass напрямую.

Запустить обновление вручную: вкладка Actions → «Обновить данные Новосибирска» → Run workflow.

В OpenStreetMap есть не все сайты, поэтому перед звонком проверяйте по Яндекс Картам или 2ГИС.

## Запуск у себя

```bash
python -m http.server 5190
```
