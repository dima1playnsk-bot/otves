# Отвес — бизнесы без сайта на карте

Сайт находит местные бизнесы, у которых нет своего сайта: парикмахерские, кафе, автосервисы, стоматологии и ещё 16 видов. Нужен, чтобы искать клиентов на разработку сайтов.

Сайт: https://dima1playnsk-bot.github.io/otves/

## Как работает

1. Выбираете город (или просто двигаете карту) и виды бизнеса.
2. Сайт спрашивает у OpenStreetMap все такие места на видимой части карты и делит их на «есть свой сайт» и «нет своего сайта».
3. «Нет своего сайта» — это когда сайта нет вовсе или вместо него стоит ссылка на ВКонтакте, Telegram, Taplink, DIKIDI, YCLIENTS и т. п.
4. Точки сетей (у которых в OpenStreetMap указан бренд) по умолчанию скрыты: им сайт не продать.
5. Каждого можно проверить кнопками «Яндекс Карты», «2ГИС», «Найти сайт», поставить статус и написать заметку.
6. Все отмеченные попадают во вкладку «Мои лиды», оттуда их можно скачать файлом для Excel.

Статусы, заметки и последние ответы серверов хранятся только в браузере (localStorage). На сервер ничего не отправляется.

## Откуда данные

- Бизнесы — [OpenStreetMap](https://www.openstreetmap.org/copyright) через Overpass API. Сайт по очереди спрашивает несколько серверов: `maps.mail.ru` (VK), `overpass-api.de`, `overpass.private.coffee`, `overpass.kumi.systems`. Если они перегружены, ответ может идти до минуты.
- Поиск города — Nominatim.
- Карта — MapLibre GL и [OpenFreeMap](https://openfreemap.org).

В OpenStreetMap есть не все бизнесы и не все сайты. Поэтому «нет сайта» здесь означает «нет сайта в OpenStreetMap» — перед тем как писать, проверьте по Яндекс Картам или 2ГИС.

## Технологии

HTML, CSS и JavaScript без сборки. Ключи и регистрация не нужны.

## Запуск у себя

```bash
python -m http.server 5190
```

и открыть http://127.0.0.1:5190
