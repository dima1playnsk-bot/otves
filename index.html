    Как пользоваться
    1. Найдите город, выберите, кого ищем, и нажмите «Искать». Большой город лучше смотреть по районам.
    2. Проверьте каждого по кнопкам «Яндекс Карты» и «2ГИС». В OpenStreetMap сайт мог просто не попасть.
    3. Ставьте статус. Список хранится в этом браузере, во вкладке «Мои лиды» его можно скачать для Excel.
    4. Пишите и звоните каждому лично. Одинаковая рассылка по SMS и почте без согласия нарушает закон о рекламе.

    Сюда попадает каждый, кому вы поставили статус или написали заметку. Чтобы убрать из списка, верните статус «Новый».
